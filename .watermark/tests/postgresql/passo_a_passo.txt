================================================================================
PASSO A PASSO — Super Teste METRO: Incremental Append (MaxValue)
================================================================================

Pré-requisitos
--------------
1. .env configurado com METRO_STACKOVERFLOW_POSTGRES_DATABASE e METRO_DEVELOPMENT_STORAGE_BASE_PATH
2. Watermark API no ar: cd .watermark && uvicorn app:app --port 8000
3. venv ativo e metro instalado (pip install -e .)

Tasks utilizadas
----------------
- Plano:       tasks/incremental_append/test_watermark_append.yaml
- Particionado: tasks/incremental_append/test_watermark_append_partitioned.yaml

Comando base
------------
metro run <task> --secret-provider local --watermark-api-url http://localhost:8000

================================================================================
RESUMO SEMÂNTICA APPEND
================================================================================

| Operação na origem | Capturado pelo Append? | Efeito no Parquet        |
|--------------------|------------------------|--------------------------|
| INSERT novo        | Sim                    | Nova linha adicionada    |
| UPDATE (last_update)| Sim (como nova linha) | Duplicata com novo valor |
| DELETE             | Não                    | Linha permanece no Parquet|

Verificação de watermarks via API:
  curl http://localhost:8000/watermarks/raw.test_watermark_append/last_update
  curl http://localhost:8000/watermarks/raw.test_watermark_append_partitioned/last_update
