================================================================================
TESTE MANUAL — Incremental Append / MaxValue (Watermark)
================================================================================

Objetivo
--------
Validar que o Append:
  1) na 1ª execução processa o dataset completo e cria o watermark;
  2) nas execuções seguintes processa apenas registros com
     last_update > watermark e acrescenta Parquets;
  3) UPDATE com last_update maior entra no append;
  4) DELETE na origem NÃO remove dados já materializados no Target
     (comportamento esperado do Append — não é CDC).


Pré-requisitos
--------------
1. Database do watermark criado:
     psql -U postgres -h localhost -p 5432 -f .watermark/setup_watermark.sql

2. Variável no .env (raiz do METRO):
     METRO_WATERMARK_POSTGRES_DATABASE="postgresql://postgres:SENHA@localhost:5432/metro_watermark"

3. API no ar:
     cd .watermark
     ..\venv\Scripts\uvicorn.exe app:app --reload --port 8000

4. Tasks:
     tasks/incremental_append/test_watermark_append.yaml
     tasks/incremental_append/test_watermark_append_partitioned.yaml


Comando base do METRO
---------------------
metro run tasks/incremental_append/test_watermark_append.yaml ^
  --secret-provider local ^
  --watermark-api-url http://localhost:8000

(Para particionado, use test_watermark_append_partitioned.yaml)
